# FastMap

FastMap is a federated multi-cohort fine-mapping method that approximates PIPs generated by joint-modeling method like SuSiEx.
It is computationally lightweight and can scale to a large number of cohorts. Its inputs are the SuSiE outputs from cohort-separated 
fine-mapping and it doesn't need in-sample LD file transfers.

## Repository layout

- `fastmap/` — the main algorithm: the core combination logic
  (`fastmap.py`), and the pairwise coloc scoring it calls (`coloc.py`).
- `scripts/production/` — sample scripts that read per-cohort SuSiE output and real-data summary
  statistics into the `region_df` / `pips_df` inputs `fastmap.fastmap.combine_region`
  expects, and run FastMap at a given setting (`run_fastmap.py`, `fastmap_sources.py`).

## Installation

```
pip install -r requirements.txt
```

Python 3.10+.

## Usage

For a working example of how to run it, use the provided production script:

```
python scripts/production/run_fastmap.py --help
```

`scripts/production/fastmap_sources.py` expects your data to be in GCS and will look for paths under the`FASTMAP_DATA_ROOT` environment variable by default.
